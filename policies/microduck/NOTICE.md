# Microduck official policies (bundled)

The ONNX files and `manifest.json` in this folder are the official Microduck policies by Pollen Robotics,
downloaded from the Hugging Face model repository `pollen-robotics/microduck-policies`
(https://huggingface.co/pollen-robotics/microduck-policies). The model page shows the license "apache-2.0".

They are bundled unmodified and used for inference only. `LICENSE` in this folder is the Apache License 2.0 text
(copied from the `microduck_rl` repository by Pollen Robotics, which uses the same license).
Versions and training sources are in `manifest.json`; the full third-party list is in `THIRD_PARTY.md` at the repository root.
