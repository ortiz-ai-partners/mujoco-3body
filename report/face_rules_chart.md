# 跳跳の表情の決め方（図）— レポート用

ゆうころ 10/28 夜「レポートを書くときはチャート図を作ったらいいかもね」。`crab_face.py` の 17 規則を、入力（推論・計測）→ 優先順位つきの判定 → 表情 の形で図にしたもの。Mermaid 記法（GitHub の README や Notion のコードブロック、VS Code のプレビューで図になる）。

## 入力

```mermaid
flowchart LR
  subgraph AI1[支配人 AI（固定ルール／Q 表／PPO）]
    M[次の一手を選ぶ<br/>SEAT / PUSH / BACK_OFF / STANDUP / WALK_ON / WAIT]
  end
  subgraph AI2[気分ネット（2 つ目の AI、53-32-32-5 MLP）]
    N[毎制御ステップ推論<br/>成功・止まる・転ばせる・空振り の確率<br/>渡れる確率]
  end
  subgraph MEAS[計測（MuJoCo の物理量）]
    F[パッカンへの接触力 N ÷ 10]
    C[押している時間（接触、1 秒の途切れは継続）]
    P[進み：2 秒窓で動いた距離]
    D[パッカンの姿勢（転倒）と位置（渡り切り）]
    T[自分の傾き]
    E[手の結末（成功／止まった／転ばせた）]
  end
  OBS[支配人の観測 46 次元<br/>＋ いまの手 ＋ 経過時間] --> N
  M --> OBS
  N --> R[表情の規則（17 本、上から順に）]
  F --> R
  C --> R
  P --> R
  D --> R
  T --> R
  E --> R
  R --> FACE[表情 11 種 → 表示パネル／顔モニター]
```

## 判定（上から順に、最初に当てはまった規則で決まる）

```mermaid
flowchart TD
  S([毎制御ステップ 0.02 s]) --> R1{自分の傾き 50° 超?}
  R1 -- はい --> F1[ぐるぐる]
  R1 -- いいえ --> R2{パッカンが転んだ直後 1.5 s?}
  R2 -- はい --> F2[ガーン]
  R2 -- いいえ --> R3{渡り切った?}
  R3 -- ダンス中 --> F4[にっこり]
  R3 -- まだダンス前 --> F3[キラキラ]
  R3 -- いいえ --> R5{直前の手が成功 2 s 以内?}
  R5 -- はい --> F5[ほっ]
  R5 -- いいえ --> R6{坂挑戦を見ている?}
  R6 -- 足踏み・後ずさり・座り込み --> F6[困り]
  R6 -- 登っている --> F7[にっこり]
  R6 -- 救助の場面 --> R8{押している（接触中）?}
  R8 -- 止まる＋転ぶ ≥ 40% / 転ぶ ≥ 30% / 進みなし 3 s --> F8[困り汗]
  R8 -- 力 ≥ 0.7 / 接触 5 s 超 --> F9[＞＜汗]
  R8 -- それ以外 --> F10[＞＜]
  R8 -- 押していない --> R11{直前の押しが止まった・転ばせた?}
  R11 -- はい（成功の線を超えるまで） --> F11[困り]
  R11 -- いいえ --> R12{この手の成功確率 vs スキルごとの線}
  R12 -- 困りの線以下 / 押しで転ぶ ≥ 30% --> F12[困り]
  R12 -- にっこりの線以上 --> F13[にっこり]
  R12 -- 間 --> F14[真剣]
  R12 -- 様子見: 渡れる ≥ 60% / ≤ 30% --> F15[にっこり / 困り]
  R6 -- 自分の登坂 --> F16[真剣]
  R6 -- その他（戯れ・待機・移動） --> F17[まる目]
```

## しきい値の出どころ

| 値 | 線 | 決め方 |
|---|---|---|
| 成功確率 | にっこり／困り（スキルごと） | 見送り分で「うまく終わった手の 8 割が上」「失敗した手の 8 割が下」になる値（PUSH 0.99／0.06、STANDUP 0.98／0.75、WALK_ON 0.99／0.29、BACK_OFF 1.00／0.42、SEAT 0.04／0.05） |
| 止まる＋転ばせる | 40% | 成功 60% の裏返し |
| 転ばせる | 30% | 転倒は最悪の結果なので低い線（押しのみ） |
| 力 | 0.7（0.55 で解除） | 押している間の接触力 中央値 6.4 N、最大 13.5 N を 10 N で割った目盛り |
| 接触時間 | 5 秒 | ゆうころの指定 |
| 進み | 2 秒窓で 2 cm 未満（押し中は 3 秒） | 坂の入口で 2 秒止まって寄り直す動作を数えない |
| 渡れる | 60%／30% | 様子見のときだけ |
